# Execution-plan schema

Use a live execution plan for substantial, uncertain, cross-boundary, or
multi-session work. Keep active plans under `docs/exec-plans/active/` and move
completed plans to `docs/exec-plans/completed/`.

## Required sections

- Goal
- Repository findings
- Constraints and invariants
- Integration points
- Approach and progress
- Decisions or contradictions discovered
- Verification
- Remaining work or completion state

Plans are working records. Update them when evidence invalidates their approach;
they do not override current product invariants or repository reality.
