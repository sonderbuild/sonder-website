# Roadmap schema

`ROADMAP.md` orders product outcomes rather than prescribing stale technical
recipes. Each outcome states its result, rationale, dependencies, acceptance
criteria, integration proof, and status.

Use explicit statuses such as `IDEA`, `NEEDS_PRODUCT_DECISION`, `BLOCKED`,
`READY`, `IN_PROGRESS`, `VERIFYING`, and `DONE`. Keep one primary outcome active
unless the project intentionally supports concurrent tracks. Only ready work is
eligible for autonomous selection.

Mark an outcome done only after the delivery standard has been met. Split it or
record a blocker when repository evidence shows the original scope is no longer
coherent.
