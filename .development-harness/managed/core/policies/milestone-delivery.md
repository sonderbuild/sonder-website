# Milestone delivery

An outcome is done only when its intended behavior is implemented, production
wiring is present, applicable persistence and integration effects are handled,
and proportionate verification has passed or remaining runtime validation is
explicitly identified.

Before completion, update durable architecture or product documentation when
reality changed, update the roadmap and execution plan accurately, self-review
the final diff, and create a bounded commit when the repository workflow uses
commits. Do not use implementation completion or a passing isolated test as a
substitute for this delivery standard.
