# Self-review

Before declaring a substantial outcome complete, inspect the final diff as an
independent reviewer. Check product and architecture fit, incomplete production
integration, ownership or concurrency errors, persistence and migration risk,
failure paths, permissions, unreachable code, accidental debug artifacts,
unrelated changes, test quality, target or build configuration, and
documentation or roadmap drift.

Resolve material findings within scope. If an issue is outside the requested
outcome, leave it unchanged and report it only when it materially affects the
work or requires a future decision.
